## PR #609 — feat(wdtt): WDTT client, subscriptions, AWG linking, FreeTurn improvements

**Ссылка:** https://github.com/hoaxisr/awg-manager/pull/609

**CI:** Frontend checks ✅, Swagger drift ✅

**Вердикт:** можно мержить **после одного фикса** (см. Major ниже). В остальном PR качественный, тесты `go test ./internal/wdtt/... ./internal/freeturn/... ./internal/childproc/...` проходят.

### Что хорошо

- **SSRF-гард** на URL подписки: блок loopback/link-local, перепроверка редиректов, лимит тела 1 MiB
- **childproc:** fail-closed при пустом/неверном SHA256, общий пакет для freeturn/wdtt
- **Конкурентность:** изоляция срезов в `Store.Load`, сервисный `sync.Mutex` на Create/Update/Delete/Import
- **Fail-closed:** `Enabled` только после успешного старта; ошибки Save/Get штампа туннеля не глотаются; linked-туннели удаляются только после успешного Update
- **WDTT:** матч AWG-туннеля только по peer pubkey; `lastWgConfig` переживает вытеснение из лога; автостарт клиентов на бооте

### Замечания

| Severity | Проблема | Рекомендация |
|---|---|---|
| **Major** | `RefreshSubscription` делает Load-modify-Save **без `s.mu`**, в отличие от остальных методов (`internal/wdtt/subscription_refresh.go:47–59`) | Обернуть блок Load-modify-Save в `s.mu.Lock()` / `defer s.mu.Unlock()` — как в `UpdateClientInstance` / `ImportLink` |
| Low | SSRF: LAN (RFC1918) намеренно разрешён + окно DNS-rebinding | Документировано в коде; для admin UI на роутере приемлемо |
| Low | FreeTurn не чистит linked-туннели при смене peer (WDTT — чистит) | Follow-up для консистентности |
| Low | `RefreshSubscription` не перезапускает running-клиент | Ожидаемо, но стоит явно показать в UI |

### Связь с #608

Этот PR **включает все коммиты из #608** (+22 сверху). Если мержим #609, #608 можно закрыть как superseded.
