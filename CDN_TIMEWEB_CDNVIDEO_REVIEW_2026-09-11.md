Дата: 2026-09-11

## Timeweb Cloud CDN

### Что подтверждено

- В актуальной документации Timeweb Cloud для CDN указаны только методы `GET`, `HEAD`, `OPTIONS`; подключить дополнительные методы нельзя.
- Можно использовать домен или IP как origin, собственный домен раздачи, HTTPS и пользовательские заголовки к origin.
- Текущая публичная цена: 1 ₽ в месяц за ресурс и 0,6 ₽ за ГБ исходящего трафика.
- В документации старой CDN-платформы Timeweb встречается возможность включать POST/PUT и другие методы. Это конфликтует с новой документацией `timeweb.cloud`; ориентироваться нужно на интерфейс реально создаваемого ресурса и письменный ответ поддержки.

### Пригодность

Для текущего Xray XHTTP `packet-up` через GET сервис может оказаться пригоден, если CDN:

- не буферизует ответ целиком;
- пропускает chunked/streaming response;
- допускает длительный запрос;
- не кэширует выбранный путь;
- сохраняет query string и нужные заголовки;
- имеет достаточные origin/read timeouts.

Поддержку WebSocket для произвольного origin официальная документация не подтверждает. Наличие HTTP/2 и HTTP/3 не означает поддержку WebSocket Upgrade. Поэтому `yac-ws-bridge` или Telegram Web Proxy через WSS на Timeweb нельзя планировать без минимального стендового теста.

### Оценка

Timeweb — самый доступный по цене вариант из рассмотренных. Его разумно проверять первым именно как обычный GET/XHTTP origin proxy. Не следует сразу переносить рабочий домен: сначала отдельный тестовый ресурс и без чувствительных данных.

## CDNvideo

### Что подтверждено

- Документация HTTP-ресурса позволяет включать POST, PUT, DELETE, PATCH, PROPFIND, MOVE, COPY, LOCK, UNLOCK, PROPPATCH и MKCOL; GET, HEAD и OPTIONS разрешены всегда.
- Публичные тарифы на 2026-09-11 начинаются с 5000 ₽/месяц за пакет 2 ТБ. Включены API, правила кэширования, логи, статистика, HTTP/2/3 и SLA 99,9%.
- CDNvideo использует WebSocket в собственном продукте чата (`wss://chat.cdnvideo.ru/...`). Это подтверждает наличие WebSocket-инфраструктуры компании, но не подтверждает, что обычный пользовательский HTTP CDN-ресурс может проксировать Upgrade к произвольному origin.

### Пригодность

Для динамического HTTP-трафика CDNvideo выглядит гибче Timeweb благодаря методам и расширенным настройкам. Но для нашего WSS-сценария перед оплатой необходимо получить от поддержки точные ответы:

1. Поддерживает ли стандартный HTTP acceleration resource `Connection: Upgrade` / `Upgrade: websocket` к пользовательскому origin?
2. Каков максимальный lifetime idle/active WebSocket-соединения?
3. Буферизуются ли streaming/chunked GET responses?
4. Можно ли полностью отключить кэш для заданного path?
5. Какие connect/read/send timeouts доступны?
6. Сохраняются ли query string, `Host`, `Sec-WebSocket-*` и пользовательские заголовки?
7. Допустим ли bidirectional application traffic по условиям услуги, а не только доставка статического/видеоконтента?

### Оценка

Покупать пакет за 5000 ₽ только ради эксперимента нерационально. Сначала запросить тестовый период или технический proof-of-concept. Публичные материалы упоминают тестовый трафик для отдельных видеопродуктов, но не гарантируют бесплатный тест обычного HTTP CDN.

## «Белые списки» операторов

Ни Timeweb, ни CDNvideo публично не гарантируют доступность своих пользовательских CDN-доменов в каких-либо специальных режимах сети мобильного оператора. Российская компания, российские PoP или известный ASN сами по себе такой гарантии не дают. Доступность может различаться по оператору, региону, доменному имени, IP/PoP и времени.

Корректная проверка — только разрешённый тест собственного обычного HTTPS-ресурса с нескольких сетей. Нельзя считать результат одного технического домена гарантией для всех пользовательских доменов и последующей эксплуатации.

## Рекомендация

1. Создать дешёвый тестовый ресурс Timeweb.
2. Проверить обычный HTTPS GET, длительный streaming GET, отсутствие кэша и XHTTP на отдельном пути.
3. Не рассчитывать на WebSocket, пока поддержка Timeweb письменно его не подтвердит.
4. Написать CDNvideo перечисленные семь технических вопросов и запросить trial/минимальный тестовый тариф.
5. Если CDNvideo подтвердит generic WebSocket pass-through, провести короткий тест до покупки пакета.
6. Не связывать поддержку протокола с предполагаемым нахождением домена в операторских списках — это разные свойства.
